# ポートフォリオサイト（my-portfolio-hp）

自身の制作実績やスキルをまとめたポートフォリオサイトです。  
シンプルで見やすく、PC・スマートフォンのどちらからでも快適に閲覧できる構成を意識して制作しました。

## 公開URL
- https://norihumi.github.io/my-portfolio-hp/

## 使用技術
- HTML5（セマンティックHTML / BEM記法）
- CSS3（レスポンシブデザイン対応）
- JavaScript（バナー・チラシ画像のモーダル表示）

## 工夫した点
- **制作物に合わせた表示方法の切り替え**：Webサイトは別タブで直接確認できるようにし、バナーやチラシはページ遷移せずにその場で拡大確認できるモーダル表示を実装しました。
- **保守性を意識したCSS設計**：BEM記法を採用し、セクション単位でクラス名とスタイルを整理しました。
- **デバイス幅に応じたレイアウト調整**：スマートフォン幅（768px以下）では余白・文字間隔を調整し、PC用の強制改行（`<br>`）を非表示にして自然な折り返しになるよう工夫しています。
